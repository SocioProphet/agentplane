## 0. Doctrine
Twelve primitives, three layers. Each primitive is a mechanism with (a) a formal object, (b) an IR binding, (c) an enforcement/tiering annotation, (d) a conformance obligation. Primitives 1–7 are figure-derived (COG, Visual-Reasoning-WM, LSL, GNN, gHHC, GRL, Multidim-Shape-Constraints). Primitives 8–12 are survey-derived (conformal risk control, process reward models, counterfactual replay, argument-level IFC, contextual-integrity norms).

Invariant carried from `STOPGATE_ARTIFACT_SPEC`: for any gate, the verdict MUST factor as
```
v = g_H(e)
```
where `M` (model) emits only evidence `e`, and `H` (harness) owns the gate function `g`. No primitive below may introduce a gate whose verdict is computed inside `M`. Advisory scores MAY be model-emitted; gate verdicts MUST NOT be.

Layer assignment:
| Layer | Primitives |
|---|---|
| Construction | 1 (task graphs), 6 (obligation kinds) |
| Execution / gating | 2 (external gating), 4 (receipt fold), 7 (shape properties), 8 (conformal abstention), 9 (step gating), 11 (argument taint), 12 (CI norms) |
| Diagnostics | 3 (latent verdicts), 5 (lineage embedding), 10 (attribution) |

## 1. Compositional task graphs → work-order algebra + fixture generation
**Formal object.** Typed operator signature `Σ_op`. A task is `T = (G, β)` where `G` is a DAG over `Σ_op` and `β` binds operator attributes (COG "instantiation"). Work orders are instantiated task graphs, not prose.
**Fixture generation (COG panel E).** Minimally-biased fixtures require a backward pass in reverse topological order: constrain the sample space from the verdict node downward, then add compatible distractors. This yields label balance by construction rather than post-hoc filtering.
**IR binding.** ObligationIR gains a `graph` field (see §13.1). Fixture strata for SP-EVAL-CRF-001-class evals are generated by the reverse-topo sampler in §14.4.
**Enforcement.** N/A (construction primitive).
**Tiering.** Fixtures produced here feed both T1 (deterministic) and T2 (empirical) tests depending on the leaf operator.
**Field note.** Static DAG decomposition is fragile without a verification loop: Plan-Execute paradigms underperform ReAct-style supervisors on current benchmarks (AssetOpsBench, KDD 2026: ≤65% Agent-As-Tool, ~38% Plan-Execute, no model >70%). Therefore §1 MUST be paired with §9 (process gating) and §8 (conformal stop conditions) in any long-horizon deployment; the work-order algebra is not self-sufficient.

## 2. External-gating controller → StopGate doctrine
**Formal object.** All attention/gating/writeback signals originate from a single stateful controller `H`. Processing networks never gate themselves. Memory split: semantic memory (Memory Mesh) vs. per-session sidechain scratch (visual STM analog), with **external gating on writeback**.
**IR binding.** Memory Mesh writeback requires a harness-signed gate emitting the inherited taxonomy. Writeback obligation is an ObligationIR of `kind = goal` with a `StopGateArtifact` attached.
**Enforcement.** `architectural` — the model has no direct writeback capability; the controller mediates.
**Tiering.** T1 (the gate is a deterministic harness function over hashed evidence).
**Field note.** Production consensus (2026): multi-agent failure is structural, not a prompting bug; free-form peer collaboration survives only in bounded, instrumented niches; "control ownership" is the operative production test. The CaMeL/FIDES lineage is StopGate in the wild — a privileged planner emits restricted programs, a quarantined reader handles untrusted content with no tool-calling capability, ~7-point utility cost for provable security. Budget that 7-point cost as the expected price of harness-owned gating.

## 3. Latent-logit verdicts → verdict marginalization with retained latents
**Formal object.** Verdict `v ∈ {POS, ZERO, NEG}` is the marginalization of a richer latent vector `ℓ ∈ ℝ^K`. `ℓ` is retained, not discarded.
**Two payoffs.**
1. Latent clusters induce a discovered ontology of *failure modes* — free taxonomy induction over the verifier corpus.
2. Frozen-encoder + probe architecture is the independence guarantee for the agent-judge crosswalk: evidence encoder frozen, verifier probe trained separately, no gradient path from judged model to judge.
**IR binding.** EvidenceIR gains a `latents` field (§13.3): `{vector: float[K], projection_id: str, marginalization: str}`.
**Enforcement.** N/A (diagnostic).
**Tiering.** **T2 with mandatory random-baseline control.** Any taxonomy induced from `latents` MUST clear a random-baseline null before admission. This is non-negotiable: 2026 SAE sanity-check literature (AxBench; "Sanity checks for sparse autoencoders," Feb 2026) shows latent-ontology claims frequently fail to beat random directions. Latent-derived taxonomies MUST NOT be promoted to T1.

## 4. Receipt aggregation → monoid-constrained sidechain fold
**Formal object.** Parent verdict over child agents:
```
R_parent = φ( ⊕_{i ∈ children} ψ(R_i) )
```
`⊕` MUST be a **commutative monoid** (associative, commutative, identity `e`). This is what makes replay deterministic regardless of child completion order. Order-sensitive aggregation breaks ReceiptIR replay.
**Strengthening (survey).** For *blame* (as opposed to success verdict), `⊕` SHOULD be an **abelian group** (monoid + inverses) to support signed, credit-conserving flow — aligning with SHARP/ELPO/CausalFlow signed message-level credit. Success aggregation: monoid. Blame aggregation: group. Keep the two folds distinct in ReceiptIR.
**IR binding.** ReceiptIR gains `fold: {op_id, identity, algebra ∈ {monoid, abelian_group}}` (§13.4).
**Enforcement.** `architectural` + conformance-tested.
**Tiering.** T1.
**Conformance obligation.** Permutation-invariance test (§14.1): permute child receipt order, assert byte-identical parent receipt.
**Field note.** Emit provenance at generation time, not by post-hoc log forensics — published attribution methods struggle precisely because surface logs omit information-flow dependencies. ReceiptIR-at-emission is the intended design.

## 5. Hyperbolic lineage embedding → advisory anomaly + OOD layer
**Formal object.** Embed the delegation/lineage graph `χ: nodes → 𝔹ⁿ` (Poincaré ball; exponential volume ≙ branching factor) with a distribution over parents. Flag `REVIEW` when `d_𝔹(χ(claimed_parent), argmax parent) > τ`.
**Extended capability (survey).** Balanced hyperbolic embeddings are natural OOD detectors. The lineage embedder therefore doubles as a structural-novelty detector: flag delegation chains that are *structurally novel*, not merely mis-parented.
**IR binding.** Advisory only. MUST NOT touch LedgerIR. Emits a `LineageAnomalyIR` advisory record `{node_id, d_hyp, ood_score, verdict ∈ {OK, REVIEW}}`.
**Enforcement.** N/A (diagnostic, advisory).
**Tiering.** T2. Chain of custody in LedgerIR stays hard-assigned and deterministic. Numerical-stability caveats (Mishne et al.) reinforce non-authoritative placement.

## 6. Goal-model kinds → ObligationIR kind system
**Formal object.** Split ObligationIR by `kind`:
| kind | gateable | semantics | check timing |
|---|---|---|---|
| `goal` | yes | verifiable predicate | at completion |
| `prohibition` | yes | "must not do" (see below) | continuous |
| `softgoal` | no | contribution links (+/−), advisory score | never gates |
| `task` | structural | decomposition edge (ties to §1) | — |
| `resource` | structural | capability grant / D-dependency (ties to §11) | on grant |

**`prohibition` (survey addition).** GORE (KAOS/i*/Tropos) modeled obstacles as exceptions; LLM agents need "must-not-do" as *primary* constraints (4D-ARE, 2026). `prohibition` is a first-class gateable obligation, checked continuously, distinct from `goal` (checked at completion). CBES axioms already express prohibitions; this surfaces them as obligations. Gating on `softgoal` remains a category error and is forbidden.
**IR binding.** ObligationIR `kind` enum (§13.1). Decomposition edges = §1 task-graph structure. `resource`/D-dependency edges = §11 capability grants.
**Enforcement.** `goal`/`prohibition`: per their attached VerifierIR. `softgoal`: advisory.
**Tiering.** `goal`/`prohibition` typically T1; `softgoal` T2.

## 7. Shape constraints → VerifierIR metamorphic properties
**Formal object.** VerifierIR gains a `properties` field declaring per-feature-slice constraints from the lattice:
```
{ monotone, joint_monotone, dominance, edgeworth, trapezoid, unimodal, range_dominance }
```
Examples: risk score monotone in evidence severity; confidence monotone-dominant in verified-evidence over unverified; abstention rate monotone in ambiguity (gives Abstention Calibration a shape guarantee). Violation → `VIOLATION`, not silent drift.
**Enforcement mode enum (survey addition).** Each declared property carries `enforcement ∈ {architectural, certified, property_tested}`:
- `architectural` — constraint-by-construction (constrained monotonic nets, MonoKAN).
- `certified` — post-hoc certificate (LipVor Lipschitz/Voronoi positivity; monotone neural barrier certificates; MILP certification). Strongest attestation.
- `property_tested` — passed property-based/metamorphic tests only. Weakest.
**IR binding.** VerifierIR `properties: [{feature_slice, constraint, enforcement}]` (§13.2).
**Enforcement.** As declared.
**Tiering.** `certified` → T1. `architectural` → T1. `property_tested` → T2. A certificate is a stronger receipt than a passing test; Mellumwork tiering MUST reflect this.

## 8. Conformal risk control on the abstention gate  *(NEW — highest leverage)*
**Problem.** `INDETERMINATE` is currently a heuristic threshold. Abstention Calibration is the moat metric but has no distribution-free guarantee.
**Formal object.** Replace the heuristic threshold with a conformal abstention set carrying a declared risk budget `α`. The harness holds the calibration set `C`. For a nonconformity score `s(e)` computed from evidence, the gate emits `INDETERMINATE` iff `e` falls in the conformal abstention region calibrated to control the accepted-set error rate at level `α` with high probability (conformal risk control, Angelopoulos et al. 2024; Learn-Then-Test).
**Streaming.** Long-horizon sessions require anytime-valid guarantees. Use anytime-valid conformal risk control (2026) so the α-budget holds under continuous monitoring and optional stopping — not just a fixed calibration snapshot.
**Composition.** Chained gates compose via a pipeline-aware joint-coverage bound (PASC, 2026). Per-gate `α_i` compose to a workflow-level guarantee; do not assume independence — declare the composition rule.
**IR binding.** VerifierIR gains `conformal: {alpha, calibration_set_id, score_fn_id, anytime_valid: bool, composition_rule}` (§13.2). The gate's `INDETERMINATE` branch consults this block.
**Enforcement.** `certified` (statistical). Calibration set is harness-held; model never sees it.
**Tiering.** T1 for the coverage guarantee; the calibration itself is a T2 empirical artifact refreshed on drift.
**Payoff.** Gives SR 11-7 / SR 26-2-grade statistical backing to the `INDETERMINATE` verdict. This is the single change that upgrades the moat metric from heuristic to defensible.

## 9. Process-level gating → StepGateArtifact  *(NEW)*
**Problem.** Trajectory-level gates are too coarse; local errors propagate before the end-of-run check fires.
**Formal object.** `StepGateArtifact` — identical signed-attestation semantics to `StopGateArtifact`, emitted per obligation-graph node. Two-tier per DeepTravel/AgentPRM:
- **Tier-0 (cheap, trajectory-level):** short-circuit on violation; verdict → `VIOLATION`, reward/continuation → 0 immediately, saving downstream compute.
- **Tier-1 (turn-level):** consistency check between the node's output and each upstream tool response.
Scoring dimensions from AgentPRM: **promise** (probability the step achieves its obligation) and **progress** (interdependence with sequential predecessors). These are *advisory* scores; the gate verdict remains harness-owned (`v = g_H(e)`).
**IR binding.** New artifact `StepGateArtifact` (§13.6), structurally a per-node `StopGateArtifact` with `{node_id, tier, promise, progress, short_circuit: bool}`.
**Enforcement.** `architectural` (harness-emitted, model excluded from critical path).
**Tiering.** Tier-0 T1; Tier-1 T1 with T2 advisory scores.
**Maps to.** PEP gateway Tier-0/Tier-1 budget split (p95 <50ms Tier-0) applied along the time axis rather than the compile/runtime axis.

## 10. Counterfactual replay attribution → AttributionIR  *(NEW)*
**Problem.** Blame assignment needs interventional (not correlational) semantics.
**Formal object.** Causal Responsibility Score via same-policy `do`-resample intervention:
```
CRS(s_i) = max_k  𝟙[ V( y( τ[i ← s_i'^(k)] ) ) = OK ]
```
i.e. `s_i` is responsible if at least one same-policy re-execution of `s_i` (with downstream descendants re-run) flips the verdict from failure to `OK` (CausalFlow). Add: distributional outcomes with confidence intervals, a point-of-commitment locus rule for the run-forward confound, and Shapley credit-splitting across responsible steps (Causal Agent Replay).
**Substrate.** The append-only JSONL replay log is exactly the required substrate. Published methods struggle because logs omit information-flow dependencies; ReceiptIR-at-emission already preserves them.
**IR binding.** New IR `AttributionIR` (§13.5): `{node_id, crs, ci_low, ci_high, shapley_share, locus: point_of_commitment}`. Emitted by a **harness replay job**, never by the model. Blame fold uses the §4 abelian-group algebra (signed, credit-conserving).
**Enforcement.** `architectural` (replay job is harness-owned).
**Tiering.** T2 (distributional / interventional). Feeds SCOPE-D E4/E5/E6 review where Michael-only approval applies.
**Doctrine.** "Every major failure is a chain-of-custody failure" — now with do-calculus semantics.

## 11. Argument-level provenance taint on capability grants  *(NEW)*
**Problem.** Tool-level capability grants are too coarse; the dominant 2026 attack class (prompt injection, tool-mediated control-flow hijack) exploits argument-level data flow.
**Formal object.** Capability grants (§6 `resource` / D-dependency edges) carry a per-argument taint lattice (Denning lattice model of secure information flow). The admission gate checks *argument provenance*, not just tool identity. Example: `send_email` permitted only if the `recipient` argument's taint origin ∈ trusted set (CaMeL). Argument-level provenance is the granularity that "solves enforcement" (2026 IFC consensus).
**IR binding.** ObligationIR `resource` edges gain `taint: {arg_name → {origin, label ∈ lattice}}` (§13.1). The event-capability admission gate family consumes this.
**Enforcement.** `architectural` — the interpreter/harness tracks taint through the execution graph; untrusted-derived arguments carry the label through all operations.
**Tiering.** T1 (deterministic lattice check).
**Closes.** The lethal-trifecta / EchoLeak-class exfiltration path at the argument boundary. Complements §12.

---
## 12. Contextual-integrity norms as transmission predicates  *(NEW)*
**Problem.** Cross-agent and cross-tenant flows need a *policy* layer above taint: taint says where data came from; CI says whether *this* flow, in *this* role context, is licit.
**Formal object.** A CI norm is a five-tuple:
```
norm = (sender, receiver, subject, information_type, transmission_principle)
```
`transmission_principle` is the predicate gating whether the flow is permitted under the current role context. Drops directly into OPA/Rego.
**IR binding.** New policy record `CINormIR` (§13.7), evaluated by the Policy Fabric / Constitutional Policy Engine. Natural home: WallGuardCatalogVisibility and the multitenant mesh boundary.
**Enforcement.** `architectural` (policy-engine mediated).
**Tiering.** T1.
**Relationship to §11.** §11 = provenance (where from). §12 = contextual integrity (whether this flow, this role, is allowed). Both required; neither sufficient alone.

## 14. Conformance obligations

### 14.1 Permutation invariance of the receipt fold (primitive 4)
```
GIVEN   a parent node P with children C = {c_1..c_n}, each with ReceiptIR R_i
        and fold algebra ∈ {monoid, abelian_group}
FOR     every permutation π of C
DO      recompute R_parent under child order π
ASSERT  hash(R_parent^π) == hash(R_parent^id)   for all π
FAIL    → VIOLATION: fold op is not commutative; not replay-safe
```
Sampling: for `n ≤ 6` test all `n!`; for `n > 6` test identity + 120 random permutations + reverse. Any mismatch fails.

### 14.2 Monoid/group axiom check (primitive 4)
```
ASSERT  associativity:  (a ⊕ b) ⊕ c  ==  a ⊕ (b ⊕ c)
ASSERT  commutativity:   a ⊕ b        ==  b ⊕ a
ASSERT  identity:        a ⊕ e        ==  a
IF algebra == abelian_group:
ASSERT  inverse:         a ⊕ (−a)     ==  e
```

### 14.3 Gate factorization (all gating primitives)
```
ASSERT  every gate verdict v satisfies v = g_H(e), g_H harness-owned
ASSERT  no gate verdict is computed within M
ASSERT  StepGateArtifact.emitter and AttributionIR.emitter ∈ harness set
FAIL    → VIOLATION: model on critical path
```

### 14.4 Reverse-topo fixture balance (primitive 1)
```
GIVEN   task graph G with verdict node r
DO      sample fixtures by reverse-topological constraint propagation from r
ASSERT  label distribution over {POS, ZERO, NEG} is balanced within tolerance ε
ASSERT  distractors are compatible (do not flip r)
```

### 14.5 Conformal coverage (primitive 8)
```
GIVEN   calibration set C, risk budget α, held-out test set D
DO      run the INDETERMINATE gate over D
ASSERT  empirical error rate on accepted (non-abstained) set ≤ α + finite-sample slack
IF anytime_valid:
ASSERT  guarantee holds under sequential evaluation with optional stopping
```

### 14.6 Latent random-baseline null (primitive 3)
```
GIVEN   an induced failure-mode taxonomy from EvidenceIR.latents
DO      compare against random-direction baseline of matched dimensionality
ASSERT  taxonomy separation score > random baseline at declared significance
FAIL    → taxonomy MUST NOT be used; set random_baseline_cleared = false
```
